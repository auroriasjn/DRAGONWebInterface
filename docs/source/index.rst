DRAGON
================================================
DRAGON was developed in Moskowitz and Ng et al. (in preparation) to solve the problem of differentiating
between possible dual active galactic nucleus (dual AGN) candidates and galaxy merger candidates
in large sky surveys.


The DRAGON web interface serves as a convenient web interface for use in preliminary analysis of DRAGON candidates. For details on the model, please go to the DRAGON_CNN repository. We intend for the DRAGON Dual AGN candidates to be an unstructured public collaboration. We have made all of the data on these candidates (RA, Dec, J2000 objID, and even preliminary redshifts) available to be claimed.

The DRAGON web interface serves as a convenient front end for preliminary
analysis of DRAGON candidates. For model details, see the DRAGON_CNN
repository.

.. note::

   This project is under active development; contributions are welcome.
